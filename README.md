# Predictive Analytics using IBM SPSS Modeler

## 📊 Overview

This repository contains a practical demonstration of **Predictive Analytics using IBM SPSS Modeler**.

The practical work covers data preparation, data quality, data integration, exploratory analysis, relationship analysis, predictive modeling, and customer segmentation using telecommunications datasets.

## 🛠️ Tool Used

- IBM SPSS Modeler
- IBM SPSS Statistics data files
- Microsoft Excel
- Text/CSV data files

## 📚 Practicals Covered

### Practical 1 — IBM SPSS Modeler Basics
- Setting the working directory
- Creating streams
- Working with different SPSS Modeler nodes
- Creating and modifying streams
- Generating table and statistical outputs

### Practical 2 — Data Import & Measurement
- Importing Excel data
- Importing text files
- Importing IBM SPSS Statistics files
- Previewing imported data
- Setting measurement levels

### Practical 3 — Data Quality & Validation
- Auditing data
- Identifying invalid values
- Defining valid ranges
- Handling missing and blank values
- Data quality assessment

### Practical 4 — Duplicate Removal & Aggregation
- Identifying duplicate records
- Removing duplicates using the Distinct node
- Aggregating customer-level data
- Calculating number of gadgets and total revenue
- Creating one record per customer

### Practical 5 — Data Integration
- Appending records from multiple datasets
- Sorting and aggregating data
- Merging datasets
- Combining customer, call-detail and product data
- Sampling records from the combined dataset

### Practical 6 — Data Cleansing & Enrichment
- Cleaning inconsistent gender values
- Creating derived fields
- Calculating peak, off-peak and total bills
- Reclassifying fields
- Preparing data for modeling

### Practical 7 — Relationship Analysis
- Examining the relationship between churn and handset
- Analyzing churn and dropped calls
- Examining the relationship between products and revenues
- Using statistical and graphical analysis

### Practical 8 — Predictive Modeling & Customer Segmentation
- Predicting customer churn using **CHAID**
- Predicting churn using a **Neural Network**
- Comparing model accuracy
- Finding groups of similar customers using **TwoStep Clustering**
- Customer segmentation based on usage
